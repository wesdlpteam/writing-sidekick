How the Writing Sidekick handles writing

Draft for approval. The school's privacy and safeguarding leads should confirm this page, the provider settings and the retention arrangement before students use the app.

The Writing Sidekick is a web app that gives a primary student feedback on a piece of handwriting. This page explains, for parents, carers and staff, what leaves the iPad, where it goes, and what is kept. Short answer: the app itself keeps nothing, but the photo and typed writing are sent to an AI service to be read.

What the app collects

  • A photo of the handwritten page or pages, cleaned up on the iPad so the page reads white and the ink dark.
  • The typed copy of the writing, after the student has checked and fixed it.
  • The year level and the kind of writing the student chose.
  • Any sentence the student types when they try a power-up ("Revise it").
  • The feedback text, when a Listen button is tapped, so it can be read aloud.

There are no accounts, no names are asked for, and students are reminded to cover their name before taking the photo. The app has no database, no analytics and uses no cookies or browser storage.

Where it goes

  • The photo is sent to OpenAI's API to be turned into typed text.
  • The checked writing is first passed through OpenAI's safety (moderation) check, then, if it is ordinary writing, sent to OpenAI's API for feedback. Phone numbers, email addresses and street addresses are blanked out before that step.
  • Feedback text is sent to OpenAI's API to be turned into speech when a Listen button is tapped.
  • These requests pass through a small server function hosted on Vercel. It holds the OpenAI key, forwards the request and returns the answer. It keeps no copy.

How long it is kept

The app and its server keep nothing: each answer is returned and forgotten. On the iPad, the photo, typing and feedback stay in memory only until the student taps "Finish and clear", leaves the page, or leaves the iPad untouched for ten minutes (a warning shows first).

OpenAI's published API terms say content sent through the API is not used to train its models. OpenAI may keep API content for up to 30 days for abuse monitoring unless a zero-data-retention arrangement is in place for the account. The school should confirm which arrangement applies to its account and record the answer here.

Where it is processed

OpenAI processes API requests on its own servers, which may be outside Australia. The server function runs in Vercel's Sydney region. The school should confirm and record both before student use.

Saving and printing

A student can save a picture of the feedback or print it. The photos of the writing are only included when the student ticks "Include the photos of my writing"; that box is off by default. Saved pictures go wherever the iPad's Share sheet sends them, which the school controls through its device settings.

If the writing raises a concern

If a piece of writing looks like it needs a trusted adult, the app does not give writing feedback. It shows a short message asking the student to show their teacher, with a note for the teacher, and for the most serious cases the Kids Helpline number. Nothing is sent anywhere automatically; the school's own wellbeing and child-safety steps apply.
